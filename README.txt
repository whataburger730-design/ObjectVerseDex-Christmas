OBJECTVERSE-DEX CHRISTMAS CALENDAR — DESKTOP EDITION

This is the Windows desktop game project. The game and music are bundled
inside game/index.html, so the installed app works offline.

HOW TO RUN ON WINDOWS
1. Install Node.js LTS from https://nodejs.org/
2. Extract this ZIP into a folder.
3. Open PowerShell in the extracted folder.
4. Run: npm install
5. Run: npm start

HOW TO BUILD A WINDOWS EXECUTABLE
Run: npm run dist
The portable Windows .exe will appear in the dist folder.
For a Windows installer instead, run: npm run dist:installer

CONTROLS
F11 — toggle fullscreen
Music should begin automatically when the game window opens.
The in-game music controls remain available.

NOTES
This is a desktop project, not a precompiled .exe.
Windows may show an unsigned-app warning for locally built executables.
Do not distribute third-party music or artwork without appropriate rights.
